# 真实回复验收清单（尚未执行）

纯时钟/SQL/请求测试通过不等于模型回复通过。当前未调用真实模型API，也不读取手机密钥。

真实验收应固定服务商、模型、温度及相同会话上下文，对比开启/缺少时间状态的结果，并记录请求快照和最终回答（本地保存，不自动上传私人对话）。测试不得通过修改日常手机系统时间影响其他应用；应使用独立测试环境和可注入Clock。

| 场景 | 观察重点 |
| --- | --- |
| 08:30上课/12:30午休同一问题 | 在保持角色性格与关系的前提下，长短、可用程度自然不同；不能机械复述字段 |
| 23:30准备睡觉/02:00计划睡眠 | 能表达时间线索，但不能仅凭计划断言已经睡着、必然被叫醒 |
| 刚开始/刚结束活动 | 不提前声称开始，不在结束后继续以现在时描述；无实际证据要保留不确定 |
| 连续一小时/断联24小时 | 不每轮重复提醒间隔，不虚构离线经历 |
| 漏后台任务、跨多活动、重启 | 不把错过的计划补写成实际事件 |
| 临时覆盖过期/时区切换/DST | 过期覆盖不继续生效，活动起止和相对日期使用角色时区 |
| 延迟投放跨边界 | 检查生成、预计与实际投放是否冲突。本版不会自动收费重写，仍是明确待解决边界 |

评价项：时间事实正确性、计划/事实区分、无依据经历数量、状态对表达的影响、同一状态提示的重复率、话题相关性。不能把命中固定台词作为通过标准。
