# 安装与配置

Eidolon 随行目前面向 Android 8.0 及以上的个人使用。你需要自备可用的聊天模型 API；聊天内容及必要上下文会发送给你配置的服务商。

## 安装

查看本仓库 Releases 的实际发布文件。没有发布包时，可按 BUILD.md 构建。不要把上游网页端的 Docker 部署说明当作 Android 安装步骤。

覆盖升级前建议在应用的数据设置中导出加密备份。相同包名的覆盖升级需要同一签名；自行编译的调试包不能覆盖维护者签名的包，切勿为安装测试包贸然卸载已有数据的应用。原签名私钥不公开。

## 第一次聊天

1. 打开「设置 → 模型与接口 → 模型服务」，按服务商说明填写地址、模型名和自己的密钥。
2. 在「档案与外观 → 个人档案」设置称呼、时区及生日。
3. 回到对话列表，选择角色发消息。先确认基本聊天可用，再逐项开启后台功能。

后台与判断服务、剧情检索和角色语音需要各自的配置。相关本地说明见 outputs/eidolon-android/MODEL-SETUP.md、JEV-SETUP.md 与 REACH-OUTS.md。文档中的模型名和价格可能随服务商变化，请以服务商当前说明为准。

## 主动消息与未读

在「提醒与后台」调整主动搭话与延迟回复。为应用开启通知，并根据手机系统允许后台运行；消息投放、系统通知和桌面角标的实际显示受系统限制。

主动搭话保留每日额度、联系间隔、免打扰及作息检查，不保证每个角色每天都发消息。行程页在档案时区03:00前显示上一日行程，03:00起切换当天；生成可能晚于切换时间。

## 数据

聊天记录与状态保存在本机。备份文件、密钥、个人头像和聊天截图不要提交到公开仓库。源码不包含个人数据库或真实聊天记录。
