# 界面与设置归属约定

用户要求：以后新增功能时，配置界面统一归总到应用的总设置中，不隐藏在聊天发送按钮弹出的面板里。

- 新配置入口放入现有设置分组，使用带返回路径的独立页面，名称直接说明用途。
- 聊天里的图片、表情等面板只承担选择、预览、发送等当下操作；管理资源、模型、密钥、权限、角色偏好放到设置。
- 一次性确认（发送、删除、导入合并、明确付费重试）可以使用对话框。
- 不放没有实际功能的图标或开关，不为模仿截图重写原聊天/语音/数据库业务。
- 新增界面保留已有数据和配置，检查取消/返回、迟到回调、切换会话、窄屏/横屏/深色与遮挡时已读边界。

本约定从1.25的图片和表情改造继续沿用。相关已完成入口见MEDIA-UI-1.25.md。
