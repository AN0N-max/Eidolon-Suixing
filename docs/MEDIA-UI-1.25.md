# 1.25 图片/表情UI增量说明

## 用户入口

聊天→笑脸：输入框下方网格，全部/收藏/最近/系列，搜索与点击即发送。发送时不编辑语义，不进入视觉配置。输入文字会收起面板，返回先收起面板。表情以透明小贴纸呈现，名称保留在数据与无障碍标签中。

聊天→图片：调用已有系统相册，最多4张；回来后全屏预览，可勾选、查看单张大图、添加文字、确认发送或取消。大图返回先回已选列表，再返回聊天；取消保留已有图片草稿，重新进入图片入口会恢复草稿。发送失败不自动重试，预览仍在。图库权限与样式均沿用系统选择器，未自建相册或扫描用户所有照片。

设置→聊天与关系→表情包资源库：导入、收藏、搜索、分页、编辑语义与权限、清理未使用资源；历史图片和消息保留。设置→聊天与关系→角色表情偏好：切换角色、频率、主用/次选/禁用系列和用途/风格。设置→模型与接口→图片与视觉识别：默认关闭，启用服务仍需用户自行配置。旧184张ZIP及其配置继续可用，无需重复导入。

## 实现与文件清单

- 新增assets/ui/media-picker.js：独立聊天底部选择面板、会话身份与迟到结果隔离、全屏图片预览。复用mediaLibrary/mediaDraft/mediaPick/mediaSend，没有第二套发送或媒体存储。
- 新增assets/ui/media-settings.js：由原media.js拆出管理、编辑、角色偏好和视觉配置，改为总设置路由中的页面，复用原接口和参数。
- assets/ui/media.js：保留图片URL/查看/消息渲染等原助手，按消息类型添加透明表情样式，接收导入事件并分发；原入口转向新界面。
- assets/ui/media.css：两行输入工具栏、底部网格、横向系列标签、紧凑表情、全屏选图/预览、横屏/窄屏/深色适配。
- assets/ui/app.js、settings.js、index.html：注册新页面和脚本、表情与图片按钮、返回处理；总设置直接列出角色偏好和视觉配置。
- assets/ui/inbox.js：聊天被选择/预览界面遮挡时暂缓已读确认。assets/ui/call-screen.js只增加接管屏幕时收起媒体界面的UI调用，不改拨号/录音/模型/合成业务。
- WebActivity.java：只调整mediaPick入口的用途检查，设置内单图导入不要求打开聊天；普通图片发送仍要求原会话。已有Photo Picker、回退选择器、图片处理、草稿和发送链路继续复用。
- tests/media-ui.cjs更新为真实页面/假桥流程回归；sticker-packs-ui.cjs等待合并完成后再断言，适配管理页不再是弹窗；unread-entry-ui.cjs移除旧网页通知弹窗假设。构建/测试路径、版本和应用内更新公告更新到1.25/code80。

没有修改数据库表、备份版本、人物/关系/记忆/日程/日记、语音业务或角标实现。资源保存在原媒体库中；原识图和聊天模型调用方式、频率、权限及系列排序保持1.24。

## 后续界面约定

新增功能的配置入口统一登记到总设置的对应分组，使用可以返回的设置页面。聊天中的按钮、底部选择器和预览只负责当下的查看、选择、发送；不把模型、权限、角色偏好或资源管理藏在发送弹窗里。确认发送、删除、付费重试等一次性确认可保留对话框。已有与本次无关的设置实现不擅自重做。详见[界面约定](UI-GUIDELINES.md)。
