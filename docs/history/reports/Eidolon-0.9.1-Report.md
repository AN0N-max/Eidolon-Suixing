# Eidolon 随行 0.9.1

**历史包说明：本包曾错误沿用测试版身份。当前交付请使用 0.9.2 原版升级包，其包名与签名已改回 0.8.8 原版。**

本版基于用户提供的 `Eidolon-0.9-Patch.zip` 和 `Eidolon-0.9.apk`，不再以此前的 0.8.8 包作为交付基线。

## 安装与保留的数据

包名 `com.eidolon.sc.mobile.voicetest`，versionCode 27，版本名 0.9.1。与提供的 0.9 APK 保持同一证书，使用完整 Activity/JobService 类名，可覆盖升级 0.9。聊天数据库只新增两张表；原有聊天、档案和语音私有文件目录继续沿用。请先导出备份，再覆盖安装，不要先卸载。

签名证书实际 SHA-256：`1e08a903aef9c3a721510b64ec764d01d3d094eb954161b62544ea8f187b5953`。它与 0.9 的 APK 实际证书指纹相同。所用公开调试密钥来自 uber-apk-signer 官方仓库的 `src/main/resources/debug.keystore`，不是从 APK 反推出私钥。

## 已加入的功能

- 0.9 的八个可编译语音／主题源文件合并进原工程，接上播放状态、暂停继续、已保存语音和夜间模式原生入口。使用补丁内与 0.9 APK 相符的 UI 资源继续修改。
- 聊天页「显示」合并日文和小喇叭开关，可分别控制并记住。隐藏小喇叭后不为播放器保留气泡底部空白，缺中文时仍能补译。
- 本地信箱与日记页：角色筛选、已读状态、手动写作、日中双语阅读和关系阶段限制。日历及设置均可进入。
- 自动写作设置：默认关闭；最近七天聊过且达到信任的角色可自动来信。普通信件五天内不重复，生日／节日可额外触发，每天最多三封。日记依据喜欢的礼物、关系升档与特别日子，在次日开始补写最近七天事件。应用内定期检查，后台由 Android JobScheduler 安排，省电限制会延迟。
- 后台模型用于写作，未单独配置则继承聊天模型；不额外做剧情检索。来信最多参考最近八条消息；旧日期日记仅参考当天事件。缺少中文时尝试补译一次。最近一封信的摘要及已读状态可供之后聊天回忆。
- v6 加密备份增加信件、日记与事件依据，仍兼容旧备份。恢复和新写作按事务处理；关系未开放的日记正文不传给 WebView。

## 验证范围

已通过 Android API 35 编译、DEX 转换、ZIP 对齐与 v2/v3 签名验证。合并后通过 45 项核心检查、67 项功能检查、21 项前端 DOM／桥接模拟检查，以及真实 SQLite 的迁移和事务检查；覆盖旧聊天保留、v6 备份加密往返、重复记录、日记正文隔离、语音控制与两个显示开关。旧 MP3 格式断言按 0.9 的 PCM 流式实现更新。

未调用真实模型或语音 API，也未连接手机做安装、视觉或音频验收。手机端由用户自行验收。

## 后续范围

当前完成来信和事件日记这一阶段。角色专属作息、洗澡延迟、约定日历、六回合关键关系剧情、ASMR 环境音尚未移植。现有聊天数据库没有可靠的初次认识日期，因此没有用更新时间伪造百日或周年纪念日。语音文件仍不包含在聊天加密备份中。
