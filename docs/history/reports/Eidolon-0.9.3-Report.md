# Eidolon 0.9.3 · 行程与作息

本版继续 Hibi 迁移计划的下一阶段，并保持 **0.8.8 原版** 的安装身份。

## 使用入口

安装后打开「设置 → 行程与作息 → 行程与作息设置」，开启角色行程，可单独开关睡眠状态，并设置每日自动安排人数上限。默认关闭，默认自动上限三位角色。行程也可从日历页查看；聊天标题下的活动文字可点击进入。

## 行为

- 从 Hibi 的固定提交导入 28 位角色年龄及作息描述；没有对应档案的角色使用应用已有资料。按制作人档案时区，在每天 05:00 后为最近七天聊过的角色生成，优先最近聊天的角色。
- 每份行程包含起床、入睡、3–6 段活动和 0–2 个日常变数。只使用后台模型生成一次，未单独配置则继承聊天模型；读取当前状态不增加模型请求。自动失败当天不再重复尝试，可以手动重试。
- 聊天可感知当前活动、自由空档、临睡、睡觉和被叫醒。连续聊天半小时后恢复清醒状态，较长停顿后可以继续睡。跨午夜入睡按前一天的计划处理；时间回退不会伪造聊醒状态。
- 睡眠状态启用时，角色睡着会暂停主动搭话；制作人仍可以主动发消息。行程与日记关联时，计划只作为背景，不能被当作已完成的经历。
- 0.9 的流式语音、暂停续播、语音保存及夜间模式，以及 0.9.1 的统一日文／小喇叭开关、信箱与日记继续保留。

## 数据与安装

包名 `com.eidolon.sc.mobile`，版本 0.9.3 / versionCode 29；使用 0.8.8 原版的 `local-test.jks` 签名。已核对证书 SHA-256 与原版一致：`d576e97cae45aca6dedb80064e56a2aae97553fdaa8705904b63420b1d4503db`。可覆盖原版 0.8.8 及后续原版升级包。请先备份，不要卸载原版。

数据库新增行程表，聊天与信件日记表不重建。加密备份升至 v7，带上行程及失败尝试，兼容 v1–v6。恢复前验证角色、日期、时间范围、活动重叠和数量；恢复中的旧生成请求不能重新写回。瞬时的夜间聊醒状态保存在本机设置，不作为长期资料备份。

## 验证

通过 Android API 35 编译、DEX 转换、APK 对齐和 v2/v3 签名；确认实际 DEX 包含 Manifest 各组件。完成 45 项核心检查、67 项既有功能检查、33 项行程检查、25 项前端 DOM／桥接模拟检查，以及 SQLite 升级和恢复事务检查。覆盖凌晨入睡、跨午夜、时区、聊醒、时钟回退、备份加密往返、非法模型结构和状态刷新。八个 0.9 语音／主题源文件与用户提供的补丁仍一致。

没有调用真实模型或语音 API，没有连接手机做验收。实际生成效果和手机后台调度由使用者验证；自动任务可能受 Android 省电策略延迟。
