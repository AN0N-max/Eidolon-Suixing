# Eidolon 0.9.2 · 0.8.8 原版升级包

本版纠正此前 0.9.1 的覆盖目标。吸收 Work 版 0.9 的功能，但安装身份明确沿用 **0.8.8 原版**。

- 包名：`com.eidolon.sc.mobile`。
- 版本：0.9.2 / versionCode 28，高于原版 0.8.8-dev / versionCode 21。
- 签名：电脑原有 `work/android-signing/local-test.jks`，别名 `local-test`。
- 证书 SHA-256：`d576e97cae45aca6dedb80064e56a2aae97553fdaa8705904b63420b1d4503db`，与保存的 0.8.8 原版 APK 一致。

保留已合入的流式语音、暂停续播、语音保存管理、夜间模式、信箱、事件日记及统一日文／小喇叭显示菜单。自动来信和日记仍可在设置中开启。

原版聊天数据库从 v5 升至 v6，只新增信箱和事件表。包名与原签名一致，覆盖安装会沿用原版数据空间、Android Keystore 密钥、配置和私有文件。请先导出备份，直接安装本包，不要卸载原版。测试版的数据属于另一个应用空间，不会自动迁到原版。

此次更改仅修正安装身份、版本号、签名构建配置与说明。重新完成编译、DEX、APK 对齐、v2/v3 签名以及针对 0.8.8 原包的覆盖条件检查；Activity 和两个 JobService 的完整类名均有实际 DEX 定义。前轮功能检查结果见 0.9.1 说明。本轮未连接手机做安装验收。
