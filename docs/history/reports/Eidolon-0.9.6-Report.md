# Eidolon 0.9.6 · 主动搭话定时修复

每日固定时间模式原先在首次轮询时以“当前时刻”计算下一次时间。如果后台任务恰在设定时间之后几秒才运行，会将本次触发顺延至第二天，造成设定时间没有消息。0.9.6 改为以最近一次用户聊天时间计算每天的触发点；轮询晚到时会补上当天尚未完成的触发。关系随机间隔与次数、关系、睡眠和静默条件保持原样。

手机上原先已启用主动搭话，设置为每天 10:50；JobScheduler 后台任务存在并有运行记录。使用 0.9.6 覆盖安装后，在手机上强制运行一次真实后台任务，角色模型实际返回了消息；系统记录为 `reach-history-v2`，这是应用在跨应用聊天悬浮横幅成功显示后使用的低打扰记录通道。此操作实际消耗了一次聊天模型请求，并保存了一条主动消息。它验证了后台模型调用和悬浮窗显示链路；系统自然轮询的日后触发仍取决于手机省电策略。
