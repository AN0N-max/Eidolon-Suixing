# Eidolon 0.9.5 · 约定与兑现

继续 Hibi 的个人功能迁移，覆盖目标仍是 **0.8.8 原版**，没有切换到 `.voicetest` 测试版。

## 使用入口

安装后进入「设置 → 约定与兑现 → 约定设置」，开启功能；「从聊天中自动识别」可独立开启，默认均关闭。日历页也有「约定」入口。可以手动创建事项和日期范围、关联礼物、改期、取消或确认完成；可按角色与进行中／已结束筛选。模型提取记录可展开查看原话依据。

## 本次实现

- 原话中有明确承诺与明确日期时才自动记录。日期由手机按制作人时区解析，支持今天、明天、后天、星期、周末、月底、月底前以及明确公历日期。未知或含糊表达不猜测；新日期最多两年内，范围最多 32 天。
- 自动提取、改期与取消复用后台分析，不增加第三路分析请求。完成判断复用判断模型，只有明确说已完成时才检查，在约定期间与截止后三天最多检查三项；完成概率至少 0.8，且通过本机肯定完成用语检查。
- 送出关联礼物可兑现开始前一天至截止后三天内的对应角色约定；明确约好来聊天，由约定日内下一轮成功聊天兑现。修改或取消先于聊天兑现处理，不能把取消误记成完成；语音朗读不能兑现通话约定。
- 已有聊天和主动搭话可在前一天提醒、截止当天下午问起、逾期前三天表达一次失落。只在回复保存成功且实际引用原约定时标记；逾期扣分还要求回复实际表达未完成或失落。失败、停止、只看页面、过时回复或改期后的旧提醒不会消费标记。
- 好感规则参考 Hibi：兑现 +2、失落后兑现 +1；提前首次改期 0，其余改期 -1；提前取消 -1，其余取消 -2；首次逾期失落 -3。关闭好感或关系冷却期间不加减；约定单独造成的扣分最低到 10，不开启新的冷却。重复操作不重复扣奖。
- 约定变更、兑现及首次失落作为日记依据保存，与个人状态、聊天／送礼记录共同提交事务。不是直接生成一篇日记；自动日记仍需打开原来的写作开关，按原规则次日生成。
- 修复弹窗表单内选角色／礼物时，选择器覆盖原编辑表单的问题；现在会保留已填内容。

## 消耗与适配差异

手动记录、改期、完成和查看日历不请求模型。开启自动识别但关闭自动记忆时，可能增加一次后台请求；有明确完成说法且存在候选约定时，可能增加一次判断请求。两路均可独立配置，未配置则继承聊天模型。

每次向模型提供最多八件精简的进行中约定，不重复附带完整证据和元数据。手机内最多 50 件进行中约定、共 300 件记录；可删除已结束项释放容量。

相对 Hibi 服务端，手机端保留完成与取消历史，不自动删除长久逾期项，也不每天重复抱怨。没有另建准点闹钟、强制后台常驻或突破免打扰／省电限制；主动消息沿用原有时间、次数和睡眠限制。模型识别与判断仍可能有误，可手动核对。

## 安装与数据

版本 0.9.5，versionCode 31，包名 `com.eidolon.sc.mobile`。签名证书与原版 0.8.8 一致，SHA-256 为 `d576e97cae45aca6dedb80064e56a2aae97553fdaa8705904b63420b1d4503db`。安装 `Eidolon-0.9.5-original-upgrade.apk` 覆盖原版；请先备份，不要卸载原版。此包不用于覆盖 `.voicetest`。

数据库版本保持 v7，约定保存在个人资料 JSON；加密备份升到 v8，兼容 v1–v7，验证角色、唯一 ID、日期、数量、状态和原话长度后恢复。旧备份没有约定字段仍可使用。API 密钥、通用偏好开关和已保存语音文件仍按原方式管理，不作为本次个人资料备份的一部分。

保留先前的日文与小喇叭显示开关、声音／振动横幅、角色行程睡眠、来信日记、流式语音和夜间模式；八个 Work 0.9 语音／主题源文件未改变。

## 核对结果

通过 Android API 35 编译、DEX 转换、APK 对齐、v2/v3 签名和原版证书比对；实际 DEX 中含 Manifest 声明的组件，`resources.arsc` 未压缩。完成 45 项核心、67 项既有功能、33 项行程、61 项约定规则检查；前端 DOM／桥接模拟 33 项，以及六组 SQLite 迁移、隔离、FTS、事务恢复检查。

没有连接手机验收，没有调用真实模型或语音接口；手机显示、模型输出质量及后台实际调度由使用者自行验证。
