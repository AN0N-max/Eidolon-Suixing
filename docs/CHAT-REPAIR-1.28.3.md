# 1.28.3 聊天修复操作说明

- 聊天顶部“显示”→关闭“显示日文原文”，只隐藏日文。中文里的日文姓名、引号及术语保留；小喇叭按原语音语言设置朗读，不受隐藏开关影响。找不到可靠日文时显示明确状态，缺中文时仍可显式“检查并补中文”。该操作可能产生原服务费用，应用不会自动补全。旧混写通过读取兼容；不会批量改聊天记录。某些无法确定归属的混写正文保持可见，部分朗读会明确提示未纳入的片段。
- 在底部打字，键盘展开后消息区域随实际窗口缩小，最新消息保持在输入框上方；向上读历史时保留阅读位置，可用原“回到最新消息”。“键盘弹出时隐藏底部导航”开/关均保留。草稿、光标和组合输入使用同一输入框。
- 表情面板或聊天表情气泡长按查看释义；也可点击旁边“释义”，键盘使用Shift+F10或上下文菜单键。只显示资源库实际存在的资料，缺失时提示暂无释义。短按仍发送/预览。编辑、导入及角色偏好继续在总设置。
- 模型历史请求现在区分各条消息的原始时间和当前时间，保留生成/投放与间隔。历史“明天”相对于那条消息当时的日期；“八点那条”不会被应用标注成用户现在当地八点。应用提供正确依据，模型仍可能理解有误；本轮未使用真实付费服务测试回复质量。

升级沿用原签名，数据库与加密备份18保持，旧安装包保留。尚无Android真机键盘/触摸/音频验收；若手机表现仍异常，可提供具体页面与现象，不能把桌面假桥通过当作设备已通过。
