# Eidolon 随行

**把和她的日常，留在聊天列表里。**

Eidolon 随行是基于 [Eidolon-SC](https://github.com/Sallyn0225/eidolon-sc)、参考[「山茶日记」Eidolon Hibi](https://github.com/x499806631-commits/Eidolon-Hibi) 部分玩法开发的 **Android 手机 APP**，围绕《偶像大师 闪耀色彩》的角色交流，着重营造**像在聊天软件里与她保持联系的对话感**。

你可以随手发一句今天发生的事，等她回消息；隔一会儿再打开，接着之前的话题聊。开启相应功能后，她也可能先发来消息，说起自己的安排，或写下一封信。聊天列表、消息气泡、时间分段、未读提醒和通知，把这些零碎的往来留在一起，让熟悉感在一次次对话中慢慢积累。

> 本项目为非官方粉丝作品，角色由 AI 扮演，与原作版权方无关。需要自行配置模型服务，调用可能产生费用。当前开发版本为 **1.14**。

## 手机上独立运行，记录留在本机

装在手机里就能使用，无需部署服务器，也不需要电脑一直开着。聊天记录、记忆、日程和待发送内容在手机本地保存，排程与等待时间也在本地计算。**AI 回复需要自行配置外部模型 API**，生成时会发送必要上下文；本地 APP 不等于离线大模型。

## 让消息有自己的节奏

### 延迟回复：发完消息，可以先去做别的事

开启后，应用会根据她当时的行程，从你设定的范围中安排回复时间。空闲时短一些，吃饭、排练或工作时久一些；睡眠中可以等到预计醒来，也可以允许困倦回复。

消息先保存，回答准备好后在本机暂存，到时间再进入聊天。A 的会话等待时可以切去和 B 聊，A 的回复不会抢走 B 的页面。等待时间由本地规则决定，不会为“延迟多久”单独请求判断模型。

入口：**设置 → 提醒与后台 → 根据行程延迟回复**。

### 主动搭话：她也会先来找你

你不在聊天页面时，她也可以按联系间隔、关系和作息获得主动发消息的机会。今日计划能查看安排时间、执行情况和没有排上的原因，频率与每天的额度可以自己调整。

当前版本不再要求上一条主动消息必须得到回复，但仍遵守角色范围、每日额度、免打扰与作息。开启主动搭话不保证每个人每天都发消息。

入口：**设置 → 提醒与后台 → 主动搭话**。

### 系统通知弹窗：收到消息时有个提醒

消息可以通过手机自带的通知横幅提醒，点击对应通知进入相应会话。**1.12 已取消应用内与跨应用自绘弹窗**，避免同一条消息出现两张卡片，不需要“显示在其他应用上层”权限。

是否弹出横幅、声音、振动和锁屏显示由系统通知设置共同决定。正在阅读对应会话时，消息直接刷新。

### 未读角标：看见以后，再算读过

头像与底部“对话”显示未读数；只打开 APP 或列表不会把所有未读清空。消息实际可见后确认已读，并同步桌面角标。Vivo／iQOO增加兼容更新，桌面上显示数字还是圆点由手机系统决定。

### 剧情索引：剧情资料需要自己准备

**APP 不附带完整剧情库。** 想让她在聊天时检索相关剧情，需要自行寻找、整理兼容的剧情文本，再通过应用的导入入口建立本地索引。内置基础人设与角色资料不等于原作剧情全集，也不会自动把完整剧情下载到手机。

入口：**设置 → 聊天与关系 → 剧情库**。导入格式与打包方式按页面说明操作；新增剧情需要再次导入。

[查看完整功能介绍、默认延迟范围与设置入口](docs/FEATURES.md)

## 聊天之外，也有她的日常

她可以有每天的大致安排，也有自己的睡觉、起床和洗澡时间。开启相关功能后，这些状态会影响聊天语气、回复时机与主动联系。

信件、日记、约定、纪念日和关系变化，则让一些对话有了后续。配合记忆与聊天总结，可以保留提过的事情，并查看、修改整理结果。角色提示词也支持逐人编辑，按自己的偏好调整相处方式。

这些功能需要在设置中开启，部分依赖后台模型或判断服务。行程与日记是应用生成的内容，不代表角色真实生活或原作中已经发生的经历。

## 为手机上的个人使用而做

本版将日常聊天与相关数据管理放在 Android 应用内，无需让电脑持续运行后端。聊天记录保存在本机，提供加密备份与恢复；模型生成仍通过你配置的外部 API 完成，相关上下文会发送给对应服务。

界面提供浅色与深色模式、字号调整、个人头像，以及按用途分组的设置入口。

## 如何开始

Android 8.0 及以上。安装包使用下方1.12直接下载链接，也可按[构建指南](docs/BUILD.md)从源码构建。

1. 安装应用，在「设置 → 模型与接口」填写服务地址、模型名和自己的 API 密钥。
2. 完善称呼、时区等个人档案，选择角色开始聊天。
3. 按需开启主动搭话、延迟回复、行程、信件与日记；根据手机提示检查通知与后台运行权限。

安装与配置见[使用指南](docs/GETTING-STARTED.md)。剧情库、角色音色和立绘素材不随公开仓库提供，需要自行准备并遵守来源条款。公开资源范围见[资源与许可](docs/ASSETS.md)。
