# 1.23 / code78：表情包整包导入

设置→聊天与关系新增“表情整包导入”，表情包资源库也可进入。一个ZIP可带入图片、名称/分类/语义、情绪/意图/语气、图片文字/梗意及可选角色偏好。先看预览和参数，确认后合并。

同图默认去重；可选择更新同图语义，已有收藏、启用状态、权限及使用统计保留。角色偏好只补充未设置角色。导入不清空聊天，不替换人物系统，沿用已有媒体和v17备份；SQLite结构与备份版本不变。

新增离线ZIP/哈希/路径/字段/角色校验。拒绝缺图、篡改、未知版本、重复或不受支持的文件，数据库批次失败回滚。当前仍为静态图片，无动画与声音。素材包单独本地交付，不预装在APK中。

验证：Release编译、原升级签名和16KB对齐通过；现有完整离线回归及新增23项生产解析/语义合并检查通过，实际144图/29角色包通过同一生产解析器（合计24项）。假原生桥页面通过144张预览、双入口、确认/取消、错误保留、重复点击保护与可选参数检查；320×568、412×915、915×412布局截图检查通过。原有通话、设置、桌面角标、公告、日记、生活、收件箱及聊天时间8组页面回归通过。

未在Android真机执行文件选择、图片解码、导入/备份往返或真实模型表情选择；没有调用付费API。静态图片语义与模型实际选择质量仍需使用中验收。详细格式、字段、实现文件和限制见[STICKER-PACK-1.23.md](STICKER-PACK-1.23.md)。
