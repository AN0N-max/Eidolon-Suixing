# 1.19 / code74：应用内电话试用版

从现有1.18增量开发。包名和原升级签名保留，SQLite及加密备份升级v16；新通话元数据表升级时保留原有消息、日记、角标和角色状态。

入口：角色聊天页 → 电话。拨打前配置原聊天模型、Fish音色/密钥，允许通知和麦克风；可在电话设置选择系统识别或兼容HTTPS音频转录接口。第一版自动轮流说话，提供静音、扬声器、打断、通知挂断、字幕与真实接通时长。主动来电独立开关默认关闭。

未完整播放的回答不会提交关系与记忆效果，通话不自动抽取稳定用户事实或约定。同角色有待回复文字时先处理再拨打；其他角色聊天/通知可用。通话记录随备份保存，恢复不重开麦克风或重新发付费请求。

构建、原签名、对齐及离线回归通过；取消/一次播放提交、内存WAV、SQLite事务、午夜/时区及假原生桥接界面验证通过。Android麦克风、蓝牙、锁屏/后台及真实语音接口未做实机验收；真实延迟和金额未测，无真实付费API开发调用。详见 CALL-SYSTEM-1.19.md 的分阶段结果和验证矩阵。

尚无自然全双工/自然语音打断，使用明确打断按钮；HTTP识别为有界整轮提交，模型完成后开始语音播放。系统无法保证强关应用后准点来电。原始输入录音不保存；合成语音沿用已有本机缓存。
