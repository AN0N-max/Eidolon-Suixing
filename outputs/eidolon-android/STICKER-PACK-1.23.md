# 1.23 表情包整包导入

在1.22/code77的实际Java原生+WebView工程上增量开发，1.23/code78。SQLite和加密备份保持v17，包名和原升级签名保留。聊天、电话、关系和记忆仍使用原有链路。

## 手机操作

设置 → 聊天与关系 → **表情整包导入**，选择本地ZIP。也可在**表情包资源库 → 导入表情整包**选择。

先校验并显示图片、名称、分类及可展开的情绪、意图、语气、图片文字和梗意。此时只写应用缓存，没有加入资源库。点击“确认合并导入”后，复用现有图片规范化、哈希寻址及表情/角色偏好存储；不需要打开某位角色聊天。

- 同图默认跳过。可勾选更新同图语义，仍保留原启用状态、收藏、角色权限、使用次数及最近使用时间。
- 可导入包中的角色偏好，但只补充尚未设置的角色，不覆盖已有角色设置。不添加另一个人物系统。
- 取消不会修改资源库。出错保留预览供重试或取消；数据库事务失败会回滚该批新增/更新，不以部分完成报告成功。进程中断后重新选择包，不自动重试或发送消息。
- 导入后的图片、语义和角色偏好沿用现有v17备份。144张精选素材本身约2MB，但所有聊天媒体合计仍受原12MB媒体备份上限约束。
- 当前显示静态图片，不导入动画或声音。输入图片会移除EXIF并走原有尺寸/压缩处理。
- 全程本地处理，不联网下载、不调用视觉/聊天/Fish API，不需要填写密钥。

## 文件与边界

新增`StickerPack.java`负责纯Java包格式、路径、类型、大小、哈希、重复项和角色偏好校验，可直接在JVM离线执行。新增`StickerPackImport.java`负责应用私有缓存、图片预览和确认合并。`MediaStore.java`仅增加原图片导入方法的字节输入重载及新资源标志，没有改表或替换数据库实现。`WebActivity.java`增加独立文件选择、应用内部预览路由及工作线程导入动作。

新增`assets/ui/sticker-packs.js`，`media.js`增加入口，`settings.js`增加直接入口，`index.html`加载脚本，`app.js`接收预览事件。字段使用文本节点显示，包内文本不作为脚本或指令执行。原有单图导入入口保留。

ZIP限32MB；manifest限1MB；每包1～400张，单图输入限12MB，全部展开内容限48MB；图片还需通过原有格式/像素/媒体库上限检查。只接受`manifest.json`及被登记的`images/文件名.png|jpg|jpeg|webp|gif`。拒绝重复文件、越界路径、未登记文件、缺图、哈希不符、未知格式版本及本机不存在的角色编号。绝不把ZIP路径直接提取到文件系统。

## 制作包

ZIP根目录必须有`manifest.json`和`images/`图片。示例：

```json
{
  "format": "eidolon-sticker-pack",
  "version": 1,
  "id": "my-pack-v1",
  "name": "我的表情包",
  "description": "本地自定义素材",
  "stickers": [{
    "file": "images/ok.png",
    "sha256": "由制作脚本计算的64位SHA256",
    "name": "收到啦",
    "category": "赞同回应",
    "description": "点头表示收到、理解或赞同。",
    "emotion": "安心,赞同",
    "intent": "确认收到消息",
    "tone": "温和",
    "ocr": "了解",
    "meme": "不确定的原作情节不推断",
    "enabled": true,
    "favorite": false,
    "characters": []
  }],
  "profiles": [{
    "character": "mano",
    "profile": {
      "frequency": "low",
      "preferred": ["赞同回应"],
      "blocked": [],
      "emotions": ["安心"],
      "style": "保持原人设，按语境选择，不强制发表情。"
    }
  }]
}
```

`characters`空数组表示原有的全部角色可用语义，非空则必须填写本机实际角色ID。`profiles`可省略，频率支持off/low/normal/high，对应关闭或原有30/5/2分钟最小间隔。名称/分类/情绪/意图/语气上限120字符，描述/OCR/梗意上限1500字符。

标准库制作脚本：`python tools/build-sticker-pack.py 素材目录 输出.zip`。自动填图片哈希、拒绝重复并输出ZIP；最终以手机预览中的生产校验为准。

## 本次本地精选包

七系列144张：吉伊卡哇24、内裤兔12、んぽちゃむ20、Esther Bunny20、兔丸24、猫与熊20、兔子100%24；29位现有角色分别补充低频或适中偏好。每张按实际静态预览人工标注中文语义与清晰可辨的日文文字，未把看不到的动画动作、原作情节当作事实。

亲密表达的使用场景明确要求服从当前关系与语境；这通过候选语义及角色原有关系上下文约束模型选择，不宣称新增了数值好感门槛。包只包含静态预览，不包含付费动画或声音资源。来源/作者信息随manifest保存，素材包单独本地交付，不预装进APK或源码仓库。公开示例仅用合成像素。
