# 手机模型配置（0.8.4）

如果旧版把百炼业务空间的 `decision-model-preview` 地址保存为“普通聊天模型”，0.8.4 会自动按百炼 System One 调用，并在设置中显示正确协议。保存设置后可点“测试已保存的判断模型”；测试只发一条简短判断请求，不产生聊天记录。失败时显示 HTTP 状态和排查方向，不显示 API 密钥。聊天生成时最多携带两段各 900 字的剧情参考，减少 DeepSeek 输入用量。

0.8.0 增加“连接并选择模型”：填入接口地址和密钥后可向兼容服务的 `/models` 查询；阿里百炼单独使用官方 `/api/v1/models` 并展示返回的模型 ID。某些兼容服务不提供查询接口，此时可以手填模型名称。为防止密钥发错服务地址，保存过的密钥只在地址与原配置相同时复用；更换地址必须重新填写对应密钥。

此前提供的“百炼角色”聊天预设属于误报，已从手机设置中移除。已有聊天模型配置不会因此被清空；仍可按服务商实际提供的接口地址、密钥和模型 ID 手动配置。**阿里百炼决策模型入口保留**：设置 → 后台与判断模型 → 判断模型 → “阿里百炼决策模型”，填写业务空间 ID（`llm-...`）、北京或新加坡地域以及该空间的 API Key；地址会自动生成，模型默认 `decision-model-preview`。该模型经 `/systemone` 返回概率，用于剧情检索与好感判断，不会生成角色回复。采用原仓库对百炼模型的概率阈值；原仓库也指出其好感判断可能偏高。选择 Jev 时仍用 Jev 的 `/systemone`。

依据本地原仓库 .env.example 的 CHAT_LLM、BACKGROUND_LLM、JUDGE 分工迁移。

- 设置 → 模型服务：聊天接口地址、密钥、模型名。继续沿用已有配置。
- 设置 → 后台与判断模型 → 后台模型：提取自动记忆、选择已有记忆。
- 设置 → 后台与判断模型 → 判断模型：好感与边界判断、剧情检索词。
- 地址、模型可留空继承聊天配置。独立地址必须使用独立密钥，不会自动把聊天密钥发往另一服务。密钥加密保存，不显示明文。恢复继承会清除该用途独立配置。
- 记忆与关系设置分别启停功能；全部开启时最多额外两次请求。一路失败不会阻止另一路及聊天。判断结果仍沿用现有概率阈值，通用聊天模型尚未按原判断模型校准。

聊天和后台模型使用 OpenAI 兼容 Chat Completions 流式接口；普通兼容判断模型也使用此协议。百炼决策和 Jev 判断使用 System One。服务地址及模型名以你购买的服务为准。Gemini 使用其 OpenAI 兼容地址，不能填写原生 generateContent 地址。DeepSeek 与其他兼容服务同理。

原网页还有 Responses、Anthropic Messages、Cloudflare Clef、Embedding 和 Rerank；此版未实现这些专用协议，不要把对应地址填进兼容接口。原网页语音合成 Fish Audio 的现有手机配置入口保留；实时语音识别和通话未迁移。手机剧情仍用本地 FTS 检索，无需向量 API。

已在连接的 iQOO 上用应用中保存的百炼配置完成一次独立判断请求，服务返回 HTTP 200；未读取或输出密钥。未改动聊天数据库或签名，支持覆盖安装。
