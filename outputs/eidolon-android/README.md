## 安装和入口

1. 先在当前原版导出备份，再将 `Eidolon-0.9.6-original-upgrade.apk` 传到手机覆盖安装。包名和签名与 0.8.8 原版一致；最低 Android 8.0，目标平台 Android 15。不要先卸载原版。
2. 「设置 → 模型服务」填写 DeepSeek / Gemini / 其他 Chat Completions 服务。密钥由 Android Keystore 加密，不传入网页。
3. 「设置 → 记忆与关系设置」开关自动记忆、聊天好感、剧情检索。默认开启；后台分析和判断各最多调用一次，增加 API 用量和等待时间。可分别在「后台与判断模型」配置，未单独配置时继承聊天模型。约定自动识别与完成判断复用这两路，不另加第三路分析。
4. 「设置 → 剧情库」导入自己的 CSV、JSON 或 ZIP，并检索、查看来源或删除。原仓库不包含剧情原文，因此 APK 不内置虚构剧情库。
5. 「设置 → 长期记忆」查看原话依据、来源角色、替代历史，编辑/删除/清空；手动记忆仍可保留。
6. 「礼物」查看每日任务；「设置 → 任务与成就」查看全局或单角色进度。奖励自动发放，无需领取。
7. 聊天右上角「…」新建/切换/删除会话及查看角色资料。结束的对话可新建；角色冷却需要等待或送礼缓和。
8. 「设置 → 备份与恢复」导出密码加密备份。备份密码遗失无法恢复。覆盖安装前保留备份，不要先卸载应用。

## 本次迁移

### 剧情检索

支持原 SCTranslationData CSV：`id,name,text,trans`，`info` 行提供剧本编号；支持游戏 JSON 帧数组，文件名如 `produce_events_100100101.json`，也支持 ZIP 中的游戏目录路径。按原角色 `speakers` 识别出场角色，跳过选项，过滤原失败结局规则；同编号优先保留 CSV 译文，JSON 不覆盖译文。导入先解析和验证，后统一事务写入；失败不部分导入。

使用 SQLite FTS4 中日文双字词索引；每轮模型扩展检索词后，按当前角色出场过滤，从最多 120 个候选中评分，最多携带 3 段相关摘录。聊天显示本轮来源，可查看原文。手动检索使用本地关键词，不调用 API。本实现没有照搬原 embedding/rerank 服务，近义语义和超大库检索效果仍需真实资料评估；不包含远程镜像同步。

限制：单文件 4 MiB、ZIP 展开读取总量 32 MiB、单次 2000 段、总库 10000 段、单段正文 20 万字符。ZIP 仅在内存读取，不按条目路径写文件。只支持 UTF-8。无来源编号的 JSON 跳过，无 info 的 CSV 以文件路径标识；不凭文件名猜测出场角色。

### 自动共享记忆

辅助模型分析当前用户原话和最近 4 条消息；每轮最多 5 条中文事实，每条不超过 200 字，需有最新用户原话中的逐字依据。保留来源角色、会话、时间及替代关系。相同有效事实去重，明确更新会使旧事实退出检索；删除替代事实可恢复旧事实；用户回到过去状态可以形成新的有效记录，避免循环。

检索先取本机相关/近期最多 20 条候选，再让模型选择相关 ID，结合关键词结果，最多携带 3 条。跨角色来源按“听说”提示，不冒称亲历。自动提取和记忆检索都不等同于原向量服务。最多保存 2000 条；手动记忆每条 500 字。删除/清空会推进版本，旧轮次不能重新写回；之后的新聊天仍可产生新记忆。

### 聊天好感

沿用原五级 -5/-2/0/+1/+2、每日正向最多 +6、越界 -10、操纵指令不加分，区间 0–100。低于 50 按每 24 小时 +10 连续恢复；到 0 进入冷却，到 10 解冻。每会话最近 8 轮累计受伤达 6 时首次提醒，达 12 或两次越界结束对话。礼物独立加分，冷却中单礼物最多 +3。新会话不继承旧会话的受伤窗口，但保留角色关系和冷却。

辅助模型返回五级概率，平局取中性，沿用原未知模型回退阈值（越界 0.7、操纵 0.4）。DeepSeek/Gemini 的概率尚未校准，不宣称判断准确率等同原专用模型。辅助分析失败不扣分，也不新增自动记忆；会提示并继续普通回复。所有状态只在完整回复成功后，与聊天一起提交事务。失败、取消或过期回调不计入。

### 每日任务和成就

北京时间每日任务：聊天 1 轮、送礼 1 次、聊天 10 轮，每项 +1 抽取。奖励去重且允许超过自然累积 7 次上限。每日自然补充不会吃掉已获的额外余额；每次批量抽取最多 100 次。

角色成就阈值：聊天 10/100/300/1000/3000 轮；送礼 1/10/30/100 次；亲近/亲密；通话 600/3600/18000/72000 秒。全局：聊过 3/10/29 位角色，亲密 1/3/10 位，相伴 7/30/100/365 天，抽取 10/50/200/500 次。第 n 阶段奖励 n 次抽取，单角色所有阶段完成奖励 1 张重置卡，均只发一次。实时通话尚未实现，所以通话进度不会伪造，也暂时不能完成全部通话阶段。

首次升级补计能从旧库确认的聊天轮次和现有关系阶段；旧版没有记录的礼物对象、历史日期不推测回填。删除聊天不会撤销已得成就。

## 数据与备份

SQLite v5 从旧版本保留聊天、会话和个人数据，支持主动搭话；送礼以对话事件写入既有消息表，礼物与个人数据在同一事务中保存。

备份 v3 使用 PBKDF2-HMAC-SHA256 + AES-256-GCM，包括聊天、个人资料、记忆、关系、任务成就和剧情；兼容 v1/v2。恢复追加会话，替换个人状态，重映射记忆/关系的会话引用，剧情按编号合并并保留译文。模型/语音密钥、服务设置和媒体不进备份。文件上限 16 MiB、聊天总文本 400 万字符、剧情备份 JSON 总量 350 万字符；大库请另外保留原始导入文件。不是原网站 ZIP 数据包格式。

WebView 从 APK 的 `assets/ui` 读取界面，通过拦截的 `https://eidolon.local/` 虚拟本地地址运行。阻止外部网页、导航、文件访问、框架和网络资源。用户/模型/剧情内容使用 DOM 文本节点显示；模型与 Fish 请求由原生代码发起。
