# 1.22 / code77：全屏语音通话

点击聊天页电话图标直接进入全屏并拨打，移除原功能介绍弹窗。参考上游实际CallLayer源码，采用角色头像、模糊深色背景、实际状态、接通时长、双语字幕和底部操作栏。支持静音、手动打断、扬声器和挂断，横竖屏适配。

设置→模型与接口→语音通话设置，集中管理系统/百炼/HTTPS识别、主动来电、自动下一轮、费用/隐私/限制说明及通话记录。原配置及密钥保留，默认继续自动轮流说话；关闭自动下一轮后可手动开始聆听。保留30分钟/60轮限制。

增加拨号与权限取消保护，退出后迟到结果不重新启麦克风；重建恢复现有通话而不重复拨号。合成语音与真实播放分开显示，麦克风采集状态和静音分开显示。全屏遮挡时不误标底层聊天已读。ASR、Fish、聊天和生活/记忆/时间仍用原链路；SQLite/备份保持v17。

Release编译、对齐、原签名、全套离线回归、新增通话规则和页面模拟通过，另有8组现有页面回归。没有本轮Android真机或真实付费API验证；实际延迟/费用未测。当前为静态头像与半双工，字幕不提供逐字音频对齐。详细文件清单、审查依据与验收边界见[CALL-UI-1.22.md](CALL-UI-1.22.md)。
