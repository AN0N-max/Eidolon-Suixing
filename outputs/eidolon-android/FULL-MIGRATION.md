# 完整 Android 迁移范围

用户于 2026-10-21 将范围从文字版扩大为全部功能。当前 Java 工程仅是未完成的基础，不是完整迁移交付。

随后用户确认：保留全部个人功能，管理与备份改为手机本地；已有部分服务及素材，名称和位置待提供。无需迁移公网多用户运营后台或部署共享服务器。

最新范围调整：不包含 AI 生图与角色发照片，不需要 NovelAI 或其他生图服务配置。既有头像、动态立绘、衣装和统计分享图仍在范围内。

设备与模型：用户提供截图为 iQOO Neo10 Pro+ / OriginOS 6 / 骁龙 8 至尊版 / 16 GB RAM / 256 GB 存储。截图未直接列出 Android 版本，不据此推断具体 API 级别。目标模型为 DeepSeek 或 Gemini；已添加官方地址与示例模型的表单预设，尚无密钥，不代表真实 API 调用已验证。预设依据 2026-10-21 官方文档：https://api-docs.deepseek.com/ 和 https://ai.google.dev/gemini-api/docs/openai 。

## 交付原则

- 不依赖电脑运行 Python 后端。
- 外部模型、语音、向量化、重排和判断服务通过用户自行配置的 API 使用。
- 未迁移、未联调、缺少素材与已验证功能分开标记；不能以页面或按钮存在视为完成功能。
- 不把普通语音朗读替代成角色音色，不把最近消息上下文描述成长期共享记忆，不把背景图片替代成动态立绘。

## 2026-10-22 · 0.5.0 更新（历史阶段）

已迁移并接入聊天和本地管理：剧情 CSV/JSON/ZIP 导入、角色出场过滤、FTS4 词索引与来源查看；自动用户事实提取、跨角色来源、替代和删除恢复；聊天好感评估、连续恢复、冷却和会话结束；原阈值每日任务与成就去重奖励。回复、个人状态与奖励在同一事务提交。v3 备份加入剧情并映射恢复后的会话引用。

适配差异：辅助模型默认复用用户的 Chat Completions 服务，概率未针对 DeepSeek/Gemini 校准；剧情及记忆采用本机关键词候选与辅助模型选择/扩展，没有配置原 embedding/rerank 服务，也没有远程剧情同步。原剧情原文不在仓库，应用提供导入入口，不能把空库说成内置全集。自动记忆在回复成功时落库，辅助分析会增加等待和一次 API 调用；可关闭。

通话成就定义已迁移，但因为实时通话尚未接入，不能累计通话时长或提前达成全角色阶段。未完成的其他范围仍为立绘、通话、结构化生日/时区、统计分享和其他协议等，详见 README。

84 项 Java 检查、真实 SQLite 迁移/事务/FTS4 过滤检查及模拟桥接的移动 UI 流程通过。没有真实 API 密钥或手机，因此真实模型判断质量、剧情检索效果和 Android 运行需后续验收。
