# 1.21 / code76：双向表情包与图片聊天

新增共享表情包库、语义管理、收藏/最近使用、角色权限与偏好；用户和角色都可发送纯表情或按序混合文字。AI使用本地少量语义候选，不随机发送，不把整个资源库装进提示词。

聊天输入栏新增表情、图片入口。图片通过系统选择器导入，支持最多4张、预览、附言、大图与历史恢复；普通图片不自动收录。媒体按哈希存一份，删除表情目录保留历史图片。

视觉默认关闭，可选择聊天模型原生识图或独立兼容视觉模型。图片/OCR分析保留不确定性，按图片/服务/模型缓存；已知表情直接用档案。不自动把附件内容写入长期用户事实，识别失败不静默重复付费调用。

SQLite与加密备份升级v17，保留原消息和角色状态。媒体文件随备份保存；总备份上限32MB、媒体12MB，超限明确报错。动态格式首版保留静态首帧。电话、TTS、延迟回复、日程、通知和角标继续沿用现有流程。

构建、原签名、原有离线回归、28项多模态规则、SQLite和8组界面模拟通过。没有真实付费API或手机安装测试；真机编解码/选择器/内存、实际视觉理解与API延迟/费用待验收。完整审查、文件清单和限制见MULTIMODAL-1.21.md。
